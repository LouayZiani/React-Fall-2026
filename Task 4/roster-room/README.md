# Roster Room

NBA front-office roster manager built with React, Vite and a simulated async API (Promises, random delays, random errors, localStorage).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Reset data

Open DevTools, Application, Local Storage, delete the `nba-roster-data` key and refresh.
